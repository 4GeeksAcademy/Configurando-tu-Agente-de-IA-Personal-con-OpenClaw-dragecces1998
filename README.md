# Configurando tu Agente de IA Personal con OpenClaw

![OpenClaw](banner.png)

Workspace del agente OpenClaw desplegado en un VPS Ubuntu 22.04 LTS.

## Stack

- **OpenClaw** 2026.7.1-2
- **Proveedor de modelo:** LiteLLM (gateway de 4Geeks)
- **Gateway:** local, bind loopback (127.0.0.1:18789), auth por token
- **Hooks:** habilitados

## Contenido

Archivos generados por OpenClaw: `AGENTS.md`, `BOOTSTRAP.md`, `HEARTBEAT.md`,
`IDENTITY.md`, `SOUL.md`, `TOOLS.md`, `USER.md`.

Proyecto de 4Geeks Academy - AI Engineering.
